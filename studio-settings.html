Troubleshooting
        
AGY not recognized? Run this in PowerShell:

        
& "$env:LOCALAPPDATA\agy\bin\agy.exe"

        
Not signed in? Run AGY and finish sign-in. "Not installed on this PC"? Run Install Repair.cmd. "Does not allow this extension"? Your companion was installed for a different copy of the extension: run Install Repair.cmd again (it allows the IDs listed in native-host\allowed-origins.json). "Could not start"? Install Node.js, run the installer again and look at native-host\host.log.

        
Account limit reached? Wait for account access to reset. Manual revision required? Edit the prompt yourself. When a repair cannot run, the prompt stops with the reason instead of being resent unchanged; fix the cause and press Retry.

      

      
Experimental: review initial repairs. Concat groups need manual revision. Local-companion original/revised pairs are saved in its repair-history (on your PC only).
